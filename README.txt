MADHAV'S BIRTHDAY SURPRISE WEBSITE
=================================

Your uploaded photos are included in the website's images/ folder and displayed in the memory gallery.

PREVIEW ON YOUR MAC
1. Extract madhav_birthday_website.zip.
2. Open index.html in Chrome, Safari, or Firefox.
3. Test the confetti, birthday tune, and interactive gift cards.

PUBLISH FREE WITH NETLIFY DROP
1. Visit https://app.netlify.com/drop
2. Sign in or create a free account if prompted.
3. Drag the extracted folder named madhav_birthday_website into the drop area. It contains index.html and the images folder.
4. Wait for deployment and copy the public URL Netlify provides.
5. Open the URL on your phone to test it, then send it to Madhav on WhatsApp before midnight.
6. Anyone with the link may be able to view the photos. Share only with people you trust.

INCLUDED
- Colourful responsive birthday page
- Madhav's name and heartfelt friendship message
- Eight photos in a memory gallery
- Confetti button and interactive gift cards
- Browser-generated birthday tune (tap to play)

No build tools or paid API are required. The tune is synthesized in the browser and is not a recording of the original Happy Birthday song.
